# Квиз по базе знаний

Статический сайт без сборки. Весь контент (статьи и вопросы) — в `data.js`.

## Деплой на GitHub Pages
1. Загрузите `index.html`, `data.js` в репозиторий (в корень).
2. Settings → Pages → Source: "Deploy from a branch" → ветка `main`, папка `/ (root)`.
3. Через минуту сайт откроется по адресу `https://<user>.github.io/<repo>/`.
